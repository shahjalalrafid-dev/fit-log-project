## 🚀 About The Project

**FitLogP** is an intuitive fitness tracking and workout planning application built with modern web technologies. It empowers users to explore a diverse library of workout plans, filter routines based on their goals, view detailed exercise breakdowns, and curate a customized personal fitness dashboard on the fly. 

Designed with a sleek, dark-mode-first aesthetic, FitPulse ensures a smooth, responsive, and engaging user experience across mobile, tablet, and desktop viewports.

---

## 🛠️ Technologies Used

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** [React.js](https://react.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
* **Deployment:** Vercel

---

## ✨ Key Features

* **📱 Fully Responsive Layout:** Meticulously optimized interface that adapts fluidly from mobile touch devices to large desktop displays without breaking layout integrity.
* **🏋️ Dynamic Workout Discovery:** Browse comprehensive workout lists featuring detailed metrics like duration, estimated calorie burn, equipment requirements, and user ratings.
* **🗺️ Smart Navigation State:** Intelligent path-based or persistent state routing that dynamically highlights active navigation tabs (Workouts vs. My Plan) upon page load or refresh.
* **📋 Personalized "My Plan" Dashboard:** Easily save your favorite workouts, mark routines as completed, and manage your daily fitness schedule in one centralized place.
* **⚡ High-Performance Image Optimization:** Leverages Next.js image handling with proper scaling to ensure workout media remains crisp and clear on high-density retina and mobile screens.
